# Nyange

A general-purpose marketplace for Uganda. Nyange owns the product catalog; sellers set prices and fulfil
order lines claimed from a geo-capped pool; Nyange's own field agents perform deliveries and other tasks.

- [`docs/architecture.md`](docs/architecture.md) - business specification: actors, workflows, rules, invariants and open questions. Technology-neutral.
- [`docs/catalog/persistence-model.md`](docs/catalog/persistence-model.md) - catalog and offer persistence model (PostgreSQL with jsonb), derived from the business specification. Draft for review.
